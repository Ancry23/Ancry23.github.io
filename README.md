# Sito personale

Sito personale di Andrei Cristian Moldovan, realizzato con HTML e CSS.

**Sito online:** https://ancry23.github.io/

## Pagine

- `index.html`: home con competenze e progetti
- `cv.html`: curriculum vitae
- `contatti.html`: form di contatto
- `privacy.html`: informativa sul trattamento dei dati

## Tecnologie

- HTML5 semantico
- CSS con Flexbox e Grid, generato da `scss/style.scss` (Sass)
- Bootstrap 5.3.3 per componenti e utilità
- Formspree per l'invio dei messaggi dal form
